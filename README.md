## ✨ عن المشروع

**رفيق القرآن للأطفال** هو تطبيق ويب تعليمي تفاعلي يساعد الطفل على حفظ **جزء عمّ** ومراجعته بطريقة ممتعة، من خلال دمج الاستماع والترديد والاختبارات والقصص والقيم والألعاب والمكافآت في رحلة واحدة.

> 🎯 **هدف المشروع:** أن يكون القرآن رفيق الطفل، لا مجرد درسٍ يحفظه.

التطبيق مصمم ليكون **Mobile First** ويدعم **PWA وOffline**، ويعمل بدون Backend في النسخة الحالية، مع حفظ تقدم الطفل محليًا على الجهاز.

## 🚀 التشغيل محليًا

لا تفتح `index.html` مباشرة عبر `file://` لأن التطبيق يستخدم `fetch()` وملفات JSON.

### Python

```bash
python3 -m http.server 8080
```

### Node.js

```bash
npx serve .
```

ثم افتح:

```text
http://localhost:8080
```

## 🌍 النشر على GitHub Pages

1. ارفع المشروع إلى GitHub.
2. افتح **Settings → Pages**.
3. اختر **Deploy from a branch**.
4. اختر الفرع `main`.
5. اختر المجلد `/ (root)`.
6. اضغط **Save**.

التطبيق يستخدم مسارات نسبية مثل `./css/style.css` و`./js/app.js`، والتنقل الداخلي يعتمد على Hash Routing، لذلك لا يحتاج Server Rewrites.

## 📴 PWA وOffline

يستخدم المشروع **Service Worker** لتخزين الأصول الأساسية وتشغيل التطبيق بدون اتصال.

يشمل التخزين:

- HTML / CSS / JavaScript
- بيانات القرآن
- القصص
- الأخلاق والتحديات
- الخطوط المحلية
- أيقونات التطبيق
- الصوتيات التي تم تشغيلها أثناء الاتصال

### تحديث الـ Cache

عند تغيير ملفات التطبيق، حدّث رقم الإصدار في:

```js
const VERSION = "v1.2.0";
```

ثم ارفع التعديل إلى GitHub.

## 📚 إضافة قصة جديدة

أضف ملف JSON جديدًا داخل:

```text
data/stories/
```

ثم أضف اسم الملف إلى:

```text
data/stories/index.json
```

مثال مبسط:

```json
{
  "id": "example-story",
  "title": "عنوان القصة",
  "category": "أنبياء",
  "stars": 3,
  "ayahRef": "سورة القصص",
  "excerpt": "وصف مختصر للقصة",
  "lesson": "العبرة المستفادة",
  "questions": [
    {
      "q": "السؤال؟",
      "options": ["الإجابة الأولى", "الإجابة الثانية", "الإجابة الثالثة"],
      "correct": 0
    }
  ]
}
```

- `id` يجب أن يكون فريدًا.
- `correct` هو رقم الإجابة الصحيحة ويبدأ من `0`.
- راجع بنية إحدى القصص الموجودة قبل إضافة ملف جديد.

## 🎮 إضافة تحدٍ جديد

1. أضف تعريف اللعبة في `data/challenges.json`.
2. أضف مولّد الأسئلة داخل `js/challenges.js`.
3. أضف نوع اللعبة إلى قائمة الألعاب.
4. اختبر اللعبة على الهاتف والكمبيوتر.
5. اختبرها أيضًا في وضع Offline.

## 💾 البيانات والخصوصية

في النسخة الحالية لا يحتاج التطبيق إلى حساب مستخدم أو قاعدة بيانات مركزية.

يتم حفظ تقدم الطفل محليًا باستخدام:

```text
localStorage
```

وتوجد وظائف للتصدير والاستيراد من خلال:

```text
App.Storage
```

### ملاحظات الخصوصية

- لا يوجد Backend في النسخة الحالية.
- لا يحتاج التطبيق إلى مفاتيح API سرية.
- بيانات التقدم محفوظة محليًا على الجهاز.
- التسجيل الصوتي يعتمد على قدرات المتصفح أثناء استخدام الميزة.
- التلاوات الصوتية تعتمد على خدمة الصوت المحددة داخل المشروع.
