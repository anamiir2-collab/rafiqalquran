# رفيق القرآن للأطفال — Rafiq Al-Quran (نسخة Flutter)

تطبيق Flutter متعدد المنصات، وهو تحويل مباشر لتطبيق الويب التقدمي (PWA)
الأصلي [rafiqalquran](https://github.com/anamiir2-collab/rafiqalquran).
المنصة المستهدفة في المرحلة الأولى: **Android**.

> **حالة المشروع: المرحلة الأولى مكتملة (التأسيس)** — راجع قسم
> «ما المنفذ وما المتبقي» في الأسفل.

---

## المتطلبات

- Flutter SDK **3.22 أو أحدث** (Dart >= 3.4)
- Android SDK / Android Studio لتشغيل نسخة Android

## خطوات التشغيل أول مرة

مجلدات المنصات (`android/`, `ios/` …) تُولَّد من بيئة Flutter المحلية
لضمان توافق إصدارات Gradle وAGP مع نسخة Flutter المثبتة عندك:

```bash
# 1) توليد ملفات المنصات داخل هذا المجلد (لا يمس lib/ أو pubspec.yaml أو assets/)
flutter create . --project-name rafiq_al_quran --org com.rafiqalquran --platforms android

# 2) تثبيت التبعيات
flutter pub get

# 3) الفحص والاختبار
flutter analyze
flutter test

# 4) التشغيل
flutter run
```

لبناء نسخة اختبار APK لاحقًا (بعد اكتمال المراحل):

```bash
flutter build apk --release
flutter build appbundle   # AAB للنشر على Google Play
```

## قرارات نقل موثقة (مهمة)

1. **الهوية اللونية**: التصميم الحالي للنسخة الأصلية بنفسجي أساسي
   `#5B45D9` مع نعناعي/مرجاني/أصفر وذهبي للمكافآت (من `css/style.css`) —
   نُقلت جميع القيم حرفيًا إلى `AppColors`. (ملاحظة: README الأصلي يذكر
   أخضر زمردي قديمًا، لكن الكود الحالي بنفسجي، وقد اعتُمد الكود.)
2. **الخطوط**: أصول woff2 الأصلية حُوّلت إلى TTF (مدعوم في Flutter):
   Tajawal 400/500/700/800 للواجهة، Amiri 400/700، AmiriQuran للنص
   القرآني. مجموعات عربية + لاتينية مدمجة في ملف واحد لكل وزن.
3. **التخزين**: مفتاح واحد `rafiq_state_v1` كما في js/storage.js، بنفس
   الحقول (profile/settings/progress/rewards/stats/lastAyah…) ليبقى
   تصدير/استيراد النسخة الأصلية متوافقًا مستقبلًا.
4. **البيانات**: لا سجلًا واحدًا للقصص في الأصل (مجلد stories/ بملفات
   منفصلة + index.json) فنُقل بالبنية نفسها دون دمج أو تعديل.
5. **القرآن كاملًا**: خلافًا لوصف README الأصلي (جزء عمّ)، ملف
   quran.json الفعلي يحوي 114 سورة / 6236 آية — وهو ما يعرضه التطبيق
   عند بناء مدينة القرآن في المرحلة الثالثة.
6. **الصوت**: نمط روابط everyayah.com موثق في AppConstants مع القرّاء
   الثلاثة (العفاسي/الحصري/المنشاوي) — الاستخدام الفعلي في المرحلة 3.
7. **بلا بيانات وهمية**: عدادات الشاشة الرئيسية تقرأ قيمًا حقيقية من
   التخزين المحلي (صفرًا عند أول تشغيل). أزرار الأقسام غير المنفذة
   تعرض رسالة تُوضح رقم مرحلتها من خطة التحويل.
